# Compliance check

Check every item, show findings in a table (check, finding, correction), apply corrections to
the text, and name open risks. This check is not legal advice; it catches errors that are most
often warned against or challenged in practice.

## AGG (Allgemeines Gleichbehandlungsgesetz)

| Check | Rule |
|---|---|
| Gender-neutral (§ 11 AGG) | Use (m/w/d) or a neutral form („Pflegefachperson") in the title. Do not use exclusively masculine forms in the text. |
| Age | No age details and no „jung", „junges Team", „Berufseinsteiger bis 30", or „Digital Native". „Berufseinsteiger:innen willkommen" without an age is allowed. |
| Origin and language | Give a language level (for example „Deutsch B2") instead of „Muttersprache" or „akzentfrei". |
| Disability | No requirements unrelated to the work („uneingeschränkt belastbar"). Work-related requirements (lifting, night work) are allowed when objectively necessary. |
| Religion, worldview, sexual identity | No requirements, except for religious employers with a protected tendency, and only when the user explicitly wants this. |
| Photo | Do not require a photo. |

## AÜG (Arbeitnehmerüberlassung)

| Check | Rule |
|---|---|
| Placement form clear | For Arbeitnehmerüberlassung, the posting must make clear that the staffing agency is the employer and the assignment is at the client. Applicants must know their contracting party. |
| Equal-pay statements | Use statements such as „Equal Pay ab dem ersten Tag" or „nach 9 Monaten" only when they apply to this role (§ 8 AÜG). Leave them out when unsure. |
| Maximum assignment duration | Do not promise a lasting assignment with the same client beyond 18 months (§ 1 Abs. 1b AÜG), unless a collective agreement permits it and the user confirms it. |
| Takeover | „Übernahme durch den Kunden möglich" is allowed; „garantiert" is not unless contractually promised. |
| Permit | Optional but confidence-building: mention the Arbeitnehmerüberlassung permit. |

## Pay transparency

| Check | Rule |
|---|---|
| Salary disclosure | The EU Pay Transparency Directive (2023/970, implementation deadline June 2026) requires applicants to learn the starting pay or a range before the interview. The cleanest solution is a range in the posting. Record its absence as an open risk. |
| No salary-history request | Do not write „bitte mit Gehaltsvorstellung und bisherigem Gehalt bewerben". The directive prohibits asking for previous salary. |
| Collective agreement | When naming one, include the pay group and agreement (for example „GVP-Tarif, EG 4, zzgl. Branchenzuschlag"). |

## Working time (ArbZG)

| Check | Rule |
|---|---|
| Realistic details | State weekly hours, shift model, and weekend work as they are. Do not say „flexible Arbeitszeit" when there is a fixed schedule. |
| Night work | Mention regular night work in the posting; it also affects allowances. |

## Data protection (DSGVO)

| Check | Rule |
|---|---|
| Information duty (Art. 13) | Include a link or notice to applicant privacy information, at the latest in the application form. Talent Hub includes this; add one sentence for applications by email or WhatsApp. |
| Data minimization | Do not ask for date of birth, marital status, religion, or a photo. |

## Advertising and competition law

| Check | Rule |
|---|---|
| No unsupported superlatives | Use „Top-Arbeitgeber", „marktführend", or „bestbezahlt" only with verifiable evidence (an award and year). |
| Client name | For Arbeitnehmerüberlassung, name the client only when the client has permitted it. |
