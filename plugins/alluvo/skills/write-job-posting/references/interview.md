# Interview questionnaire

Keep the order, but skip every question whose answer is already known (request, alluvo
context, earlier answer). Ask at most seven questions. Offer options through the question
tool, with the recommendation first.

## 1. Position and level (required)

„Für welche Position genau?" If an alluvo role catalogue is available, offer matching roles
as options.

Ask a follow-up only if unclear: level (Berufseinsteiger, erfahren, mit Fachweiterbildung,
Leitung). In nursing, the Fachweiterbildung (Intensiv, Anästhesie, OP, Gerontopsychiatrie)
is decisive for the target audience.

## 2. Work location (required)

„Wo ist der Einsatzort?" Options: city from the request; branches from alluvo; „mehrere
Standorte"; „regional flexibel (Fahrtkosten geregelt)".

For Arbeitnehmerüberlassung, the host company is often not public: use the region and
travel radius instead of the client name.

## 3. Placement form (required)

„Wie wird die Stelle besetzt?"
- Arbeitnehmerüberlassung (Zeitarbeit): employment with the staffing agency, assignment at
  the client. This must be clear in the posting.
- Direktvermittlung: direct employment with the client.
- Eigene Anstellung (internal role at the staffing agency itself).

This answer controls compliance checks and the wording of „Wir bieten".

## 4. Working-time model (required)

„Welches Arbeitszeitmodell?" Options: Vollzeit; Teilzeit (ask for the number of hours);
shift work with Früh/Spät/Nacht; weekends and public holidays; Minijob; fixed-term with date.

For shifts, ask whether a Wunschdienstplan or availability survey is offered; this is a
strong argument in nursing.

## 5. Compensation (required)

„Wie soll die Vergütung genannt werden?"
- Concrete gross monthly range (recommended): ask for the figures.
- Tariff plus allowances (GVP/iGZ/BAP-Entgeltgruppe, Branchenzuschlag, Equal Pay ab Monat X).
- Hourly pay (common for Minijob/part-time).
- No disclosure: accept only with the notice about the Entgelttransparenz obligation (see
  compliance.md); record it as an open risk.

Always ask for allowances (night, Sunday, public holiday), travel costs, and bonuses as
separate items when they are not known from alluvo.

## 6. Benefits

„Was bietet ihr, das zählt?" If alluvo provides a benefits catalogue, offer its entries as
multi-select options. Otherwise suggest: unbefristeter Vertrag, Dienstwagen oder Jobticket,
Weiterbildung, Firmenfitness, Kinderbetreuungszuschuss, Prämien. Use only what the user confirms.

## 7. Required and preferred qualifications

„Was ist Pflicht, was ist nett?" Create a required list (for example Examen, Führerschein B,
Deutsch B2) and a preferred list. Use language level instead of native language. No age limits.

## 8. Target audience and tone

Ask only if not known from alluvo: „Du oder Sie?" and „Eher sachlich oder warm?". One sentence
about the person you seek („die erfahrene Fachkraft, die Nachtdienst nicht scheut") helps the
text more than three adjectives.

## 9. Channel and delivery

Ask only if the user has not named the channel, and only in Phase 4. Options: Talent Hub or
own website, Indeed, Bundesagentur, Meta Ads, social media.

## Extract from an old posting or staffing requirement

When text or a record is available, pre-fill: position, location, placement form, working
time, compensation, benefits, qualifications, and contact person. Then ask only about gaps;
improve the old posting rather than imitating it (structure, specificity, compliance).
